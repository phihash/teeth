# teeth のデザインの決まり

値はすべて `teeth/DesignSystem/` にある。画面のコードでは、そこで付けた名前だけを使う。直書きは SwiftLint(`.swiftlint.yml`)がビルドと push 前に止めるので、ここには書かない。ここに書くのは、どの名前をどの場面で使うかという判断。

## 1. 色

### 背景

画面ごとに背景を1色決め、画面の中で背景色を混ぜない。

| 画面 | 背景 |
|---|---|
| ホーム・記録 | `sky` |
| 設定 | `mist` |
| コース選択のシート | `cream` |
| 歯みがき中 | `grape`(この画面だけ暗い背景で、文字と面は白) |

### 文字

- 主役の文字は `ink`、それに次ぐ文字とアイコンは `slate`。
- 案内や「まだ記録がない」などの控えめな文言は `slateMuted`。

### 歯みがき中のイラスト

今磨いている歯は `toothBrushing`、それ以外の歯は `toothIdle`、口の中央の光は `mouthGlow`。

### 色を足すとき

- 名前は見た目ではなく意味で付ける。`pink` ではなく、`accent` や `warning` のように何に使うかで名付ける。今ある `cream`・`sky` などは見た目の名前だが、付け替えは頼まれたときだけにする。
- 値が同じでも、意味が違えば別の名前にする。片方の色を変えたときに、もう片方まで動かないようにするため。
- 薄い色も独立した名前にする(`slateMuted` など)。画面側の `.opacity()` は SwiftLint が止める。

## 2. タイポグラフィ

- 書体はヒラギノ丸ゴの1種類で、太字も斜体も無い。強弱は大きさと色の濃さで付ける。`.bold()` を足しても日本語には効かない。
- 役割に合う名前を `Typography.swift` から選ぶ。合う名前が無いときは、画面で大きさを指定せず、`Typography.swift` に役割の名前を足す。
- 絵文字をイラストとして置くときは `.emoji(大きさ)` を使う。

## 3. 角丸

入れ子にするときは、内側の角丸を外側より小さくする(例: 外が `Radius.m` なら内は `Radius.s`)。

## 4. サーフェス(面とボタン)

- 色の付いた背景の上に面を置くときは `glass` を使う(丸ボタン、記録カード)。
- 主役のボタン(スタート)は黒地に白文字のカプセル形。丸ボタンは `glass` の円。

## 5. 画面レイアウト

push で開く画面は `.screen(タイトル, background:)` を付ける。背景・タイトル・戻るボタンがそろう。

## 6. 実装前に参照する場所

まず `teeth/DesignSystem/` の名前と、同じ種類の画面で使っているものを見る。値や部品を足すのは、どれも合わない理由を言えるときだけ。足したら、どこで使うかを一言コメントに書く。使わなくなった名前は消す(残っていると push 前の検査で止まる)。見た目を変えたら、コードだけで判断せずシミュレータで画面を見る。
